# Async Hermes Agent

A native-async, library-focused distribution derived from
[NousResearch/hermes-agent](https://github.com/NousResearch/hermes-agent) at
upstream release `v2026.8.3`.

It preserves the upstream `AIAgent`, runner, batch runner, provider, tool,
MCP, skill, memory, session, and trajectory surfaces while making the active
library path awaitable end to end.

## Install

Python 3.11 through 3.13 is supported. Install the library directly from the
release tag:

```bash
uv pip install "git+https://github.com/ykoh42/async-hermes-agent.git@v0.20.2"
```

See the full **[Installation Guide](/getting-started/installation)** for a
development checkout, optional provider dependencies, and release artifacts.

:::tip Fastest path to a working agent
Choose a current tool-capable model, provide its credential, then follow the
[Quickstart](/getting-started/quickstart). Existing upstream library call sites
normally keep their imports and add `await` at I/O-bearing calls.
:::

## What is Async Hermes Agent?

It is the retained Hermes agent harness as an async-only Python library. The
conversation loop, providers, tools, MCP, skills, memory, sessions, delegation,
trajectories, runner, and batch runner remain available under their familiar
module paths. A host application owns its own HTTP, authentication, UI, and
deployment lifecycle and awaits `AIAgent` directly.

## Key Features

- **Native async end to end** — Model, tool, MCP, session, trajectory, runner,
  and batch-runner I/O is awaited without a thread-pool compatibility fallback
- **Familiar upstream surface** — Core file locations, import paths, public
  names, arguments, and return shapes stay recognizable; I/O calls add `await`
- **Extensible tool use** — Retained terminal, file, web, browser, vision,
  skills, memory, session-search, clarification, delegation, and plugin tools
- **MCP support** — Dynamic stdio, Streamable HTTP, and SSE server discovery
  with ordered tool observations and explicit async lifecycle cleanup
- **Persistent context** — SQLite sessions, memory, user-profile context, FTS
  history search, checkpoints, and resume
- **Training-data harness** — Preserve reasoning, tool calls, observations, and
  final answers; generate JSONL trajectories with bounded batch concurrency
- **Service-ready library** — Embed the agent in FastAPI or another async host
  without bundling a second service framework or HTTP contract
- **Upstream-traceable** — Derived from Hermes Agent `v2026.8.3` with original
  source paths retained to make later migrations reviewable
