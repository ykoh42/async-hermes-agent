## Verification invariant

There are no `review-required` or unclassified entries. The retained test
manifest is checked in the order upstream sync behavior → async SQLite →
PostgreSQL; only I/O awaits, async fixtures/lifecycle, driver errors, and
FTS scoring are permitted differences. The source paths and declaration order
remain upstream-traceable, and no sync wrapper, executor, façade, registry, or
new public interface was introduced.
